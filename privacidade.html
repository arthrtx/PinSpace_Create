Política de Privacidade

Última atualização: 10 de outubro de 2026

Esta página explica que dados o PinSpace Create recolhe, para que servem, com quem são partilhados e como os podes ver ou apagar. Escrevemos em linguagem simples de propósito.

1. Quem é responsável

O PinSpace Create é um projeto independente. De momento os pedidos sobre os teus dados tratam-se diretamente no site (ver a secção 7). Um contacto direto será publicado aqui quando estiver disponível.

2. Usar sem conta

Podes usar o editor sem conta. Nesse caso os teus quadros ficam guardados só no teu navegador (armazenamento local) e não chegam aos nossos servidores.

3. Que dados recolhemos com conta

Não vendemos dados, não mostramos publicidade e não usamos cookies de rastreio ou de publicidade.

4. Base legal

  • Execução do contrato (estes termos): conta, perfil, quadros e comunidade.
  • Interesse legítimo: segurança, prevenção de abuso e spam, moderação.
  • Consentimento: funcionalidades opcionais, como ligar a tua conta SoundCloud.

5. Serviços de terceiros

  • Supabase: base de dados, contas e armazenamento de imagens.
  • Netlify: alojamento do site.
  • Google: início de sessão.
  • jsDelivr: entrega de bibliotecas de código.
  • IMG.LY (staticimgly.com): descarrega a IA de remover fundos. A imagem é processada no teu próprio navegador e não é enviada.
  • SoundCloud: só se usares o leitor de música ou ligares a tua conta.
  • Open-Meteo: previsão do tempo no início. Não enviamos a tua localização.
  • wsrv.nl: quando arrastas um link de imagem de outro site que bloqueia o acesso direto, o link pode passar por este serviço para carregar a imagem.

Alguns destes serviços podem tratar dados fora da União Europeia, com as garantias previstas no RGPD (por exemplo, cláusulas contratuais-tipo).

6. Quanto tempo guardamos

Guardamos os dados enquanto tiveres conta. Se apagares a conta, o perfil, os quadros, as imagens, os likes, os reposts, os seguidores e as notificações são apagados de imediato. Cópias de segurança técnicas dos fornecedores podem demorar algumas semanas a desaparecer.

7. Os teus direitos

Podes pedir acesso, correção, apagamento, portabilidade, limitação ou opor-te ao tratamento dos teus dados.

  • Corrigir: em Perfil → Editar perfil.
  • Apagar tudo: em Perfil → Editar perfil → Apagar conta.
  • Denunciar um problema: usa o botão de denúncia (bandeira) num quadro ou perfil.

Também podes apresentar queixa à autoridade de proteção de dados do teu país (em Portugal, a CNPD).

8. Armazenamento no navegador

Usamos o armazenamento local do navegador para manter a sessão iniciada, guardar rascunhos e preferências (idioma, tema). Não é usado para rastreio.

9. Idade mínima

Tens de ter pelo menos 13 anos para criar conta. Se tiveres menos de 16, precisas da autorização de quem tem responsabilidade parental por ti.

10. Segurança

Usamos ligações cifradas (HTTPS), regras de acesso na base de dados (cada pessoa só altera o que é seu) e proteções contra código malicioso. Nenhum sistema é infalível; se detetares um problema de segurança, usa o botão de denúncia com o motivo "Outro" e descreve o problema.

11. Alterações

Se esta política mudar de forma importante, avisamos no site. A data no topo mostra a última versão.
